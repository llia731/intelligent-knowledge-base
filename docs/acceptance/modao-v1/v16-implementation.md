# V16 个人中心与设置：实现与回归说明

基线：PR #11 head `459244f3255b9e038207779fad7694310994928c`（已通过 B01、B02、B03、B05 6/6 独立回归）。

来源：`docs/acceptance/modao-v1/v15-v16-component-plan.md`（九种真实原型交互状态）以及墨刀 ZIP 浏览器截图证据。

## 本分支完成范围

- 用 Radix Dialog 替换右侧个人中心抽屉，按原型宽 768px、主内容区域居中，保留关闭、遮罩、Escape、焦点管理。
- 增加个人资料、界面偏好、检索偏好、通知偏好四页签；页签间共用未保存的草稿，取消和 Escape 丢弃草稿。
- 个人资料：名称、头像四选一、部门。界面：主题、默认布局、紧凑侧栏。检索：模式、排序、每页条数、同义词扩展。通知：渠道、频率。
- 保存更新 `profile` 与 `personalPreferences` 同一 Zustand 事务；持久化合并时补充旧版本偏好默认值，并保留 B05 的一次性演示密钥存储清理。
- 保留原有 `#modao-personal-center` 入口及 `#role-switch` 测试入口。演示角色不属于原型四页签，作为独立开发工具列在页脚。

## 尚未完成的业务能力（不得误报通过）

- 主题、紧凑侧栏及默认知识库卡片布局未在全站实际生效：首批只实现偏好存储与界面。
- 检索页尚未读取偏好作为初始化选项；向量检索、热度排序、同义词扩展不等于已有真实服务。
- 通知设置不代表实际站内信、邮件、短信或企业微信投递。
- 墨刀原型的 PingFangSC 字体在 Codex 环境不可用，尚不能对原生字体做像素级签收。
- V15 分享弹窗、B04 细粒度角色权限仍在后续清单。
