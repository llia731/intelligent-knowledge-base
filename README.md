# 智识库

企业知识库第一版。上传文档后可以检索、问答，并按角色控制谁能看到什么。

产品逻辑分析见 [docs/product-analysis.md](docs/product-analysis.md)。墨刀原型包在 [prototype/智能知识库V1.0.zip](prototype/智能知识库V1.0.zip)。

## 现在能走通的闭环

- 上传正文或文本文件，自动分块。敏感内容或受限密级先进入审核，通过后才能被检索和问答引用。
- 检索按当前角色和知识库权限过滤。同义词扩展会改写查询。向量库只保存连接配置，未接通时用关键词召回。
- AI 问答带来源，不满意会进入审核。助手可以限制知识库范围和回答风格。
- 删除进回收站，可以恢复。角色权限决定能打开哪些页面、能否看到受限知识。
- 数据保存在浏览器本地，刷新后还在。外部模型和向量库不会假装已经连上。

## 本地运行

```bash
npm install
npm run dev
```

开发服务默认在 `http://127.0.0.1:8080`。问答需要环境变量 `XAI_API_KEY`，没有密钥时仍会展示召回的原文切片。

## 代码怎么分

```
src/routes/_app          页面
src/components           壳层和权限拦截
src/lib/kb/store.ts      文档、会话、审核、权限等状态
src/lib/kb/query.ts      谁能读、怎么排序
src/lib/kb/ask.functions.ts  问答请求
prototype                墨刀原型包
docs                     产品分析
```

## 还没做的

真实账号登录、服务端持久化、PDF/Office 解析、接通向量库和外部模型。这些不影响当前这版在浏览器里把主流程走完。
