## 里程碑与退出条件

- **M1 产品需求与源码基线**：IKB-001、002、003 完成。前端页面与业务状态逐项对应；开源研究有真实 commit 和代码出处。
- **M2 成熟 RAG 能力复现**：IKB-005 至 009 完成。使用非敏感文档可运行全链路、测试覆盖错误及中断场景。
- **M3 墨刀产品功能闭环**：IKB-010、011 完成。产品验收按原型逐项通过，权限和索引一致性测试通过。
- **M4 算法优化及部署**：IKB-012、013 完成。基线与改进能对照、部署能恢复，关键指标由项目组验收阈值确认。

## 第一批建议开工事项

1. IKB-001：逐屏拆解 prototype ZIP，补齐真实产品验收矩阵。
2. IKB-002：核查 server、migrations、src/lib/auth、src/lib/app-data，识别已存在的后端能力，避免重复开发。
3. IKB-003：在独立工作目录检出 RAGFlow 固定 Tag，沿源码核查实际检索链路。
4. IKB-005：在研究结果基础上评审统一文档、分块、证据及权限模型。

> 不推荐在完成上述工作前就开始大规模重写 RAG 代码。每个任务须通过 PR、测试和对应验收记录闭环。
