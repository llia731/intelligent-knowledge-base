# 墨刀 V1.0 全页面前端交付说明

本分支在 PR #8 的首页基线之上，补齐用户端与平台后台页面，并带上 PR #6 的内网动态模型目录。不修改 `main`。客户端演示数据不能代替服务端鉴权，也不会被描述成真实 RAG 调用。

## 页面清单

用户端：首页、知识上传、智能检索、AI 问答、知识管理、权限设置、审计日志。

平台后台：总览仪表盘、用户管理、角色权限、知识库配置、内容审核、系统日志、API 密钥。

墨刀 ZIP 另有两个未命名「画布 8」。其中一个几乎只有「页面 1」，不能当成正式页面。另一个是组件母版，正文已拆进上面的命名页面（尤其是知识管理），不单独做路由。

## 原型还原 vs 为闭环新增

还原：浅色侧栏、顶栏检索、统计卡、快捷入口、上传区、检索筛选、问答布局（新对话 / 历史 / 收藏 / 助手 / 模型下拉 / 引用）、知识库卡片与文档表、权限矩阵、审核、配置、日志和密钥页的信息结构。

新增且已标明不是原型像素：演示角色切换、进入后台、本地操作记录、以及各页上「未接入服务」的说明。知识管理分类数量按本地文档计算，不照抄原型里的 86 / 42 等示意数字。

## 已接通的交互

- 上传文本或文件，解析分块，敏感内容进入待审核，结果写进知识管理和审计。
- 知识库创建、文档筛选、编辑、删除进回收站、恢复、分享附言。
- 检索可改范围、排序，并打开来源。
- 问答支持多轮、历史、收藏、引用弹层、有用/无用反馈。模型列表只来自服务端 `getChatModels`，网关未配置时列表为空，不写死 GPT-4、Claude、文心一言、通义千问。
- 用户新增与启停、角色「查看」授权、知识库 ACL、审核通过/拒绝、分块参数保存、密钥创建/撤销、日志筛选分页。

## 仍是 Mock，下一步要换的接口

| 能力 | 现在 | 接入时替换 |
| --- | --- | --- |
| 文档、会话、审核、用户、密钥、审计 | 浏览器本地状态 | 服务端文档、会话、审核、账号、密钥与审计 API，并按登录用户隔离 |
| 检索 | 本地片段打分 | 服务端混合检索，禁止把客户端证据直接送给模型 |
| 问答 | 仅当未配置 `DATABASE_URL` 且模型在允许列表中才调用内网 `/chat/completions` | 服务端召回通过后，去掉这段保护性拒绝 |
| 模型列表 | `IKB_MODEL_BASE_URL` + `IKB_CHAT_MODELS` + `INTERNAL_LLM_API_KEY` | 保持服务端读取，不要把密钥下发到浏览器 |
| 采集同步、密钥配额、部分批量操作 | 只提示未接入 | 采集器、配额和导出接口 |
