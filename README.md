# 智能知识库（Intelligent Knowledge Base）

企业级 RAG 智能知识库产品原型与相关代码项目。

## 产品概述

这是一个基于 RAG（检索增强生成）的企业级智能知识库产品原型，覆盖：

- **用户端**：AI 问答、智能检索、知识上传与管理、会话历史与收藏
- **后台管理**：用户/角色权限、知识库配置（分块策略、模型配置）、内容审核、审计日志、API 密钥、仪表盘

支持多模型（GPT-4、文心一言、通义千问等）、敏感信息脱敏、引用溯源、权限控制等企业级特性。
