## 重要限制

1. 墨刀 `xy`、`wh`、`fill` 等字段使用私有紧凑编码；本轮未完成可信几何、颜色、字体解码。**不能将编码后的字符串直接当作像素或 CSS 值。**
2. 简单按文件行顺序或页面记录边界聚合对象是不可靠的：大量细粒度元素出现在第二个「画布 8」后面。可能涉及可复用组件及跨页面资源，必须进一步解析引用关系并用实际页面截图确认。
3. 当前独立执行容器中的 Chromium 打开本地 HTTP 页面遭遇 `ERR_BLOCKED_BY_ADMINISTRATOR`，因此这次**没有生成可信墨刀截图**。Codex Cloud 之前已经成功打开离线原型，可继续承担实际浏览器截图验收。
4. `PR #9` 的类型检查、构建与部分浏览器流程已由另一次 Codex Cloud 任务验证；14 页同视口视觉对照尚未完成。此脚本不能替代视觉验收。
