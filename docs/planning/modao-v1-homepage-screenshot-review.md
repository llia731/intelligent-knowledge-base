# 墨刀 V1.0 首页真实截图比对记录

核查依据：业务方 2026-11-04 直接提供的墨刀离线预览截图（浏览器画面约 1908×937；墨刀预览器缩放显示 52%），并附带导出包 `index.html`。

## 一、基准范围

**仅中间的首页产品画布属于应用界面。**

截图外围的“智能知识库V1.0”墨刀预览器标题、左侧画布目录、右侧批注面板、底部翻页控制和 52% 缩放控件属于**墨刀预览工具本身**，不应在 React 产品中复刻。

由于截图含预览器缩放、浏览器窗口与灰色背景，不能直接把整个 1908×937 图像当作应用设计稿尺寸。放大观察得到的产品画布约为 1920×1080 级别的桌面端布局，实际像素尺寸需进一步通过原型的设计尺寸或导出图确认。

## 三、当前实现边界

1. **只针对用户实际提供的首页截图进行了有证据的视觉重构**。另外 13 个页面尚未获取同等级设计基准，不得声称已高保真复刻。
2. 项目最初的暖色背景和深色左侧菜单，与首页原型明确不一致，本轮已经开始替换；其他业务页面可能因全局主题变更而产生回归，需要截图检查。
3. 目前首页动态、知识库数、文档数、检索和问答次数仍依赖本地 Zustand 演示数据，不能代替真实企业业务指标。
4. 顶部通知、帮助、设置图标暂为视觉元素，后续需验证墨刀原型的实际点击交互，并提供真实功能或明确未实现提示。
5. 原型首页快捷入口的“个人中心”已连接当前应用已有的个人信息侧栏。
6. AI 问答模型选择按照业务批准例外，保留原型控件交互，服务端根据实际允许的内网模型动态生成选项（另外的 PR #6）。

## 四、下一次视觉验收方法

在 152 测试机运行 `feat/modao-v1-fidelity-baseline`（PR #8），使用与设计画布接近的浏览器视口截图；必须和墨刀产品画布截图比较，**不要把墨刀预览器左右面板和灰色背景算进 UI**。

逐一检查：导航宽度、logo、顶部栏高度、五卡占比、六列快捷操作卡片、底部两栏宽度、页面留白、文字层级和颜色。对明显偏差形成后续 CSS 修正提交，不以“构建通过”作为视觉验收结论。
